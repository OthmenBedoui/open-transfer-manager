# Roadmap

## 0.1 – first public release
- [x] Multi-connection engine with pause/resume, retries, queue, scheduler, speed limit
- [x] Video & audio from 1000+ sites (yt-dlp), quality choice, playlists
- [x] Modern UI with light/dark themes
- [x] One-command installer for Linux and macOS
- [x] Browser extension for Chromium browsers and Firefox, native messaging bridge
- [ ] Official logo and icons
- [ ] Screenshots and demo GIF

## 0.2 – polish
- [ ] Publish the extension on Chrome Web Store, Firefox Add-ons, Edge Add-ons, Opera add-ons
- [ ] System tray icon / keep running when the window is closed
- [ ] Clipboard watcher (offer to download copied links)
- [ ] Translations (French first) for the app and the extension
- [ ] Checksum check (SHA-256) after download
- [ ] Drag & drop links into the window

## 0.3 – reach
- [ ] Safari extension (macOS app wrapper)
- [ ] Packages: Flathub, AUR, Homebrew cask, .deb/.rpm
- [ ] Signed and notarized macOS app bundle
- [ ] Video thumbnails and format picker in the new download dialog

## Ideas
- Torrent/magnet support through an optional backend
- Mirror/fallback URLs for one file
- Bandwidth schedule (slow during work hours)
- Web UI for the headless mode
