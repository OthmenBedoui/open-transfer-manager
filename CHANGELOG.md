# Changelog

## 0.1.0 – unreleased
First public version.
- Multi-connection downloads with pause/resume across restarts, retries with back-off, disk-space check
- Video and audio from 1000+ sites through yt-dlp (quality choice, audio formats, playlists, browser cookies)
- New interface with light and dark themes, sidebar with categories, search, details panel
- Queue, scheduler and speed limiter
- Browser extension (Chromium family and Firefox) with native messaging bridge
- `otm` command line: add, list, headless mode, doctor, update-ytdlp
- One-command installer for Linux and macOS
